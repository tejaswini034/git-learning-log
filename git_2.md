## Adding a Pull Request Template for Every Future PR

![Image](https://nextwork.ai/determined_maroon_jolly_tamarind/uploads/3ac00a14-cbfc-476a-9a2f-2d9b678880b9_03nvz0yg)

### Why the template must live on the default branch

In this project extension, I learned that the template must be on the default branch because, if not, i.e if the template file is on a feature branch, then GitHub will not find or apply the file when a new pull request is opened.
GitHub only reads and loads configuration files, workflows, and templates from the repository's default branch.
